## Working notes

The README mixes local assets with remote badge/stat services (`readme-typing-svg.demolab.com`,
`img.shields.io`). Remote services break or rate-limit without warning — check the rendered
profile on GitHub after any edit rather than trusting a local markdown preview.

Positioning currently reads "AI & Automation Studio Founder · Claude Expert · Kenya", pointing
at **hekimalabs.tech**. Keep it consistent with the personal-brand material in
`~/Billy/2. Areas/Personal Brand/` and the Hekima Labs project — when the positioning changes,
this file is one of the places that goes stale silently.
